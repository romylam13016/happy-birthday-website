# 小A 生日祝福互动网页 ✦

粉甜梦幻风格的生日祝福页：**按顺序解锁** 5 位室友的祝福，集齐后**线路点亮**，解锁**最终彩蛋**（宿舍合照 + 最后祝福）。

## 如何打开

直接用浏览器打开 `index.html` 即可（双击，或右键 → 打开方式 → Chrome / Safari）。

## 互动玩法

1. 地图上只有「冯怡心」头像亮着，其余是暗的（带 🔒，点不了）。
2. 点击发光的那位 → 弹出她的拍立得相框 + 便签祝福 → 点「🌌 回到宇宙」关闭，这位头像点亮，下一位自动亮起、可点。
3. 依次解锁：冯怡心 → 彭欣怡 → 于紫茜 → 石尚 → 林麟，线路一段段亮起。
4. 5 位全部点亮后，整条线路点亮，地图顶部出现发光彩蛋 🎁，点开就是散落摆放的合照墙 + 最后的祝福；点「🔄 重新开始」可重玩一遍。

## 放文件：全部放进 `photo/` 文件夹

把下面的文件按命名放进 `photo/` 文件夹即可，代码会**自动读取**，无需改代码：

| 用途 | 文件名 |
| --- | --- |
| 冯怡心头像 | `冯怡心照片.jpg` |
| 冯怡心与小A合照 | `冯怡心合照.jpg` |
| 彭欣怡头像 | `彭欣怡照片.jpg` |
| 彭欣怡与小A合照 | `彭欣怡合照.jpg` |
| 于紫茜头像 | `于紫茜照片.jpg` |
| 于紫茜与小A合照 | `于紫茜合照.jpg` |
| 石尚头像 | `石尚照片.jpg` |
| 石尚与小A合照 | `石尚合照.jpg` |
| 林麟头像 | `林麟照片.jpg` |
| 林麟与小A合照 | `林麟合照.jpg` |
| 最终彩蛋（合照墙，多张） | `合照1.jpg`、`合照2.jpg` ……（默认 7 张，可在 `CONFIG.final.photos` 增删） |
| 背景音乐 | `背景音乐.mp3` |

> 照片还没放进去时，头像会自动显示 emoji 占位、合照位置显示发光星星、音乐回退为内置八音盒旋律，不会报错。放好文件后**刷新页面**即可生效。

## 改文字

都在 `index.html` 里的 `const CONFIG = { ... }` 配置区：

| 想改什么 | 字段 |
| --- | --- |
| 标题 / 副标题 / 提示语 | `title`、`subtitle`、`hint` |
| 相框文字 / 便签抬头 / 按钮文字 | `frameCaption`、`noteTo`、`replayLabel`、`closeLabel` |
| 5 位室友的祝福语 | `roommates[].blessing` |
| 最终彩蛋标题 / 相框文字 / 最后祝福 / 落款 | `final.title`、`final.caption`、`final.blessing`、`final.from` |
| 头像底色 / 每个人在地图上的位置 | `roommates[].avatarBg`、`x`、`y` |

> 提示：音乐在**第一次点击后开始**，并贯穿整个游戏全程（浏览器自动播放策略要求先有一次用户操作）；「♪ 再听一遍音乐」会从头重播。
